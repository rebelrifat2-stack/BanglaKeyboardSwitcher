# Bangla Keyboard Switcher — সহজ বাংলা গাইড

একটি ছোট প্রোগ্রাম, তিনটি বাটন: **অভ্র বাংলা**, **বিজয় / SutonnyMJ**, **Regular English**।
বাটন চাপার পর Word, Excel, Notepad, Chrome ইত্যাদিতে সরাসরি টাইপ করা যায় — সুইচার খোলা না রাখলেও চলে।

> ⚠️ **সৎ অবস্থা (পড়ে নিন):** এই প্রজেক্টের দুটি টাইপিং-ইঞ্জিন (অভ্র ও বিজয়) আমি লিনাক্সে কম্পাইল করে ৪৬টি টেস্ট চালিয়েছি, সব পাস।
> কিন্তু **Windows DLL ও C# কন্ট্রোলার এখনো কোনো Windows মেশিনে কম্পাইল/চালানো হয়নি**। প্রথমবার বিল্ড করলে ছোটখাটো কম্পাইল-এরর আসতে পারে — এলে এরর লাইনটি আমাকে পাঠান, আমি ঠিক করে দেব।
> বিস্তারিত: `CHECKLIST.md`।

## কীভাবে কাজ করে (সংক্ষেপে)
সাধারণ প্রোগ্রাম অন্য অ্যাপে টাইপ করাতে পারে না। তাই এখানে Windows-এর নিজস্ব **Text Services Framework (TSF)** ব্যবহার হয়েছে — Windows-এর নিজের কীবোর্ড/IME যে পদ্ধতিতে কাজ করে, ঠিক সেই পদ্ধতি।
- `BanglaKeyboardTip.dll` = আসল ইনপুট মেথড (অভ্র ও বিজয় দুটো প্রোফাইল)
- `BanglaKeyboardSwitcher.exe` = তিন বাটনের কন্ট্রোলার; Windows-কে বলে "এই প্রোফাইল চালু করো"
- English মোড = Windows-এর নিজের English (US) কীবোর্ড (আমরা কিছুই বদলাই না)

## ⭐ সবচেয়ে সহজ উপায় (পিসিতে কোনো টুলস লাগবে না): GitHub দিয়ে installer বানান
1. https://github.com এ বিনামূল্যে অ্যাকাউন্ট খুলুন → **New repository** (নাম: `BanglaKeyboardSwitcher`, Public বা Private)।
2. ZIP আনজিপ করুন। repository পেজে **uploading an existing file** চাপুন, আনজিপ করা ফোল্ডারের **ভেতরের সব ফাইল ও ফোল্ডার** টেনে দিন (`.github` ফোল্ডারসহ — লুকানো থাকলে File Explorer-এ View → Hidden items চালু করুন) → **Commit changes**।
3. উপরে **Actions** ট্যাব → বাঁদিকে **build-installer** → **Run workflow**। ৫–১০ মিনিট অপেক্ষা করুন।
4. সবুজ ✔ এলে ওই run খুলুন → নিচে **Artifacts** থেকে `BanglaKeyboardSwitcher-Setup` ডাউনলোড করুন → আনজিপ করে `BanglaKeyboardSwitcher-Setup.exe` পাবেন।
5. লাল ✖ এলে ওই ধাপের এরর লেখাটা কপি করে আমাকে পাঠান — আমি ঠিক করে নতুন ফাইল দেব। (আমি এটা এখনো Windows-এ চালাইনি, তাই প্রথমবার এরর আসা অস্বাভাবিক নয়।)

## Word / Excel / Notepad / Chrome-এ ব্যবহার (ইনস্টলের পর)
1. Setup.exe চালান → Yes (অ্যাডমিন) → Install। শেষে **সব খোলা প্রোগ্রাম বন্ধ করে আবার খুলুন** (পুরনো প্রোগ্রাম নতুন কীবোর্ড দেখে না)।
2. **Bangla Keyboard Switcher** খুলুন (এটি সবসময় উপরে থাকে, ছোট)।
3. **অভ্র বাংলা** চাপুন → Notepad/Word/Excel-এ ক্লিক করে টাইপ করুন: `ami banglay likhi` + Space → আমি বাংলায় লিখি।
4. **বিজয়** চাপুন → টাইপ করুন (চার্ট অনুযায়ী: `Ffdm` → আমি)। Word-এ ফন্ট Kalpurush/Nirmala UI/SolaimanLipi (Unicode ফন্ট) রাখুন; SutonnyMJ ফন্ট Unicode লেখা দেখাবে না।
5. **Regular English** চাপুন → আগের মতো ইংরেজি।
6. সুইচার বন্ধ করলেও টাইপিং চলে। বদলাতে আবার সুইচার খুলে বাটন চাপুন। (বিকল্প: Windows এর `Win + Space`)
7. **Excel:** সেলে বা ফর্মুলা বারে ডাবল-ক্লিক করে এডিট মোডে টাইপ করুন। **Word:** ডকুমেন্টে ক্লিক করে টাইপ করুন।

## ২. বিল্ড
"**x64 Native Tools Command Prompt for VS 2022**" খুলে প্রজেক্ট ফোল্ডারে গিয়ে:
```bat
build.bat
```
সফল হলে `dist\BanglaKeyboardSwitcher-Setup.exe` তৈরি হবে। (বিল্ডের মাঝখানে ইঞ্জিন-টেস্টও চলে।)

## ৩. ইনস্টল
`BanglaKeyboardSwitcher-Setup.exe` চালান। **অ্যাডমিন অনুমতি চাইবে** — কারণ শুধু দুটি: (ক) Program Files-এ ফাইল কপি, (খ) ইনপুট-মেথড কম্পোনেন্ট Windows-এ রেজিস্টার করা। এর বাইরে কিছু করে না।

- কোড-সাইন করা না থাকলে SmartScreen "Windows protected your PC" দেখাতে পারে → **More info → Run anyway**। এটা এড়ানোর একমাত্র বৈধ উপায় পেইড কোড-সাইনিং সার্টিফিকেট; আমি কোনো সুরক্ষা বাইপাস করিনি।
- Windows 10 / 11 (x64) সমর্থিত। **ARM64 Windows সমর্থিত নয়।**

## ৪. ব্যবহার
1. Start মেনু থেকে **Bangla Keyboard Switcher** খুলুন।
2. বাটন চাপুন। সবুজ বাটন = সর্বশেষ বেছে নেওয়া মোড।
3. Notepad/Word/Chrome-এ ক্লিক করে টাইপ করুন।

**অভ্র:** `ami banglay likhi` → আমি বাংলায় লিখি। টাইপ করার সময় শব্দটি কম্পোজিশন (আন্ডারলাইন) হিসেবে দেখায়; Space/Enter/বিরামচিহ্নে চূড়ান্ত হয়। Backspace এক অক্ষর করে পিছায়। Esc = বাতিল।
**বিজয়:** `Ffdm` → আমি (ি-কার আগে টাইপ হয়, প্রোগ্রাম নিজে ঠিক জায়গায় বসায়)। অ ও ও ছাড়া অন্য স্বরবর্ণ = লিংক/হসন্ত (`g`) + কার-কী (যেমন ই = `g` `d`, ঋ = `g` `a`, ঔ = `g` `x`)। ৌ-কার = `c` + ব্যঞ্জন + Shift+`X`।

## ৫. সমস্যা হলে
| সমস্যা | সমাধান |
|---|---|
| "input service is not installed" | ইনস্টলার আবার চালান (অ্যাডমিনসহ) |
| বাটন চাপলে কাজ করে না | Settings → Time & language → Language → Bengali (Bangladesh) যোগ করুন, সুইচার আবার চালান |
| English বাটনে error | Settings-এ English (United States) যোগ করুন |
| Word/Chrome-এ কাজ করে না, Notepad-এ করে | অ্যাপ রিস্টার্ট দিন; ইনস্টলের আগে খোলা অ্যাপে DLL লোড হয় না |
| Administrator হিসেবে চালানো অ্যাপে কাজ করে না | Windows-এর সীমাবদ্ধতা; সাধারণ মোডে অ্যাপ চালান |
| শুধু `Win+Space` দিয়ে বদলালে সুইচারে ভুল দেখায় | সুইচার "সর্বশেষ বেছে নেওয়া" দেখায়; বাটন চাপলে ঠিক হবে |
| বিজয়ের কোনো কী ভুল মনে হচ্ছে | লেআউট আপনার দেওয়া অফিসিয়াল চার্ট (৩য় সংস্করণ) থেকে; ডিজিট-সারির বিরল লিংক চিহ্নগুলো বাদ — জানালে যোগ করব |

## ৬. আনইনস্টল
Settings → Apps → **Bangla Keyboard Switcher** → Uninstall। এটি কেবল নিজের রেজিস্ট্রি ও ফাইল মুছে — আপনার অন্য কীবোর্ড বা ডকুমেন্টে হাত দেয় না।
(ভাষা-তালিকায় আমাদের এন্ট্রি অদৃশ্য হয়ে যায়; কোনো অবশিষ্ট থাকলে Settings থেকে মুছে দিন।)
